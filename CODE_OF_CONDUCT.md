# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussions about the project. Harassment,
insults, personal or political attacks, and publishing other people's private information (including financial
information) are not accepted in issues, pull requests, discussions or any other project space.

## Reporting

Report unacceptable behaviour privately to the maintainer through a
[private security advisory](https://github.com/joaoguimaraespro/personal-finance/security/advisories/new) (the project's private channel), naming it a conduct report.
Reports are handled confidentially. The maintainer may edit or remove contributions, and temporarily or permanently
ban anyone who breaks this code, following the Covenant's enforcement guidelines.
